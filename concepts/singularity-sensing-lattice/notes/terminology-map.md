# Terminology Map

This map supports continued prior-art searching. Terms are related, not automatically equivalent.

| Term / field | Relationship to the concept | Main collision risk |
|---|---|---|
| Singular optics | Physics of wave-field singularities | Broad foundational prior art |
| Wave dislocation | Older/general term for phase singularity or nodal manifold | Early work may not use “vortex” |
| Optical vortex metrology | Uses phase singularities as metrology features | Strongest sensing-mechanism collision |
| Speckle singularity network | Many computed or physical singularities used as markers | Strong collective-displacement collision |
| Optical ruler metrology | Engineered singularities used as scale marks | Strong engineered-sensor collision |
| Singularity array | Deliberately positioned multiple zeros | Strong geometry collision |
| Vortex line / nodal line | Generic 3D zero geometry in complex scalar fields | Corrects “3D point lattice” intuition |
| Optical knot / link | Engineered 3D nodal-line topology | Strong 3D topology collision |
| Singularity sheet | Engineered 2D zero structure | Geometry and stability prior art |
| Singular skeleton | Reduced feature representation of a complex field | Information-compression collision |
| Wavefront-defect sensing | Trajectory or defect response used to infer aberration | Mode-classification collision |
| Structured-light metrology | Engineered wavefronts for precision sensing | Broad application umbrella |
| Coherent field tomography | Reconstructs media from complex-field measurements | May subsume the inverse problem |
| Inverse scattering | Maps scattered fields to objects or material parameters | Primary full-field baseline |
| Digital holography | Measures or reconstructs complex optical fields | Acquisition baseline; zeros are post-processing |
| Field-zero tracking | Generic description of tracking null locations | Search bridge across wave domains |
| Null steering | Controls directional antenna-pattern minima | Usually not volumetric singularity sensing |
| Array null space | Linear-algebraic unobservable/suppressed modes | Possible RF mathematical equivalent |
| Topological sensing | Often uses band topology or protected modes | Related language, different mechanism |
| Exceptional-point sensing | Operator eigenvalue/eigenvector degeneracy | Not a real-space phase zero; useful caution on noise |
| Coherence vortex | Zero of a correlation/coherence function | Different observable level |
| Polarization singularity | Undefined or special polarization state | Vector-field analogue, not scalar phase zero |
| Acoustic vortex / nodal line | Cross-domain mathematical analogue | May supply topology methods, not architecture proof |
| Matter-wave vortex | Quantum-wave analogue | Supports physics analogy, usually different sensing constraints |
